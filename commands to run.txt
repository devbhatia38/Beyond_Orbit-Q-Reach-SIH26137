================================================================================
QuantumRoute (Q-Reach - SIH26137) - How to Run the Application
================================================================================

Option 1: One-Click Launcher (Recommended)
--------------------------------------------------------------------------------
- Windows:
    Double-click `run_app.bat` or run in CMD / PowerShell:
    .\run_app.bat

- Linux / macOS:
    chmod +x run_app.sh
    ./run_app.sh


Option 2: Manual Terminal Execution (2 Terminals)
--------------------------------------------------------------------------------

TERMINAL 1: FastAPI Optimization Backend (Port 8000)
----------------------------------------------------
# 1. Activate Python virtual environment (if using .venv):
source .venv/bin/activate  # Linux/macOS
# or .venv\Scripts\activate on Windows

# 2. Install Python dependencies:
pip install -r backend/requirements.txt

# 3. Start the FastAPI server:
PYTHONPATH=. python -m uvicorn backend.api:app --host 127.0.0.1 --port 8000 --reload

FastAPI Docs will be available at: http://127.0.0.1:8000/docs


TERMINAL 2: Next.js Frontend Web App (Port 3000)
------------------------------------------------
# 1. Install npm dependencies:
npm install

# 2. Start development server:
npm run dev

Web App will be available at: http://localhost:3000


================================================================================
Vercel Deployment Instructions
================================================================================
To deploy this full-stack application (Next.js Frontend + Python Serverless Backend) to Vercel:

1. Push your changes to GitHub / GitLab / Bitbucket repository.
2. Go to https://vercel.com/new and import the repository.
3. Vercel will automatically detect Next.js and use `vercel.json` and `api/index.py` for Python functions.
4. Click "Deploy".
