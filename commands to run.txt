================================================================================
QuantumRoute - How to Run the Application
================================================================================

Option 1: One-Click Launcher (Recommended)
--------------------------------------------------------------------------------
- Windows:
    Double-click `run_app.bat` or run:
    .\run_app.bat

- Linux / macOS:
    chmod +x run_app.sh
    ./run_app.sh


Option 2: Manual Terminal Execution (2 Terminals)
--------------------------------------------------------------------------------

TERMINAL 1: FastAPI Optimization Backend (Port 8000)
----------------------------------------------------
# 1. Navigate to the project root:
cd d:\SIH26137

# 2. Activate virtual environment (if using .venv):
# On Windows (PowerShell):
.venv\Scripts\Activate.ps1
# On Windows (CMD):
.venv\Scripts\activate.bat
# On macOS/Linux:
source .venv/bin/activate

# 3. (First time only) Install Python dependencies:
pip install -r backend/requirements.txt
pip install -r engine/requirements.txt

# 4. Start the FastAPI server:
.venv\Scripts\python -m uvicorn backend.api:app --host 127.0.0.1 --port 8000 --reload

FastAPI Docs will be available at: http://127.0.0.1:8000/docs


TERMINAL 2: Next.js Frontend Web App (Port 3000)
------------------------------------------------
# 1. Navigate to the web directory:
cd d:\SIH26137\web

# 2. (First time only) Install npm dependencies & setup SQLite DB:
npm install
npx prisma db push

# 3. Start development server:
npm run dev

# (Alternatively, for production mode):
# npm run build
# npm run start

Web App will be available at: http://localhost:3000
